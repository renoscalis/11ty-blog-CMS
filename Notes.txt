- To ανέβασα στο GH Pages επιλέγοντας Deploy from Branch και όχι workflow actions.
- Στο μενού Settings -> Pages -> Branch επέλεξα main και /docs. 
Αυτή είναι η ευκολότερη μέθοδος για να ανεβάσεις σάιτ φτιαγμένο με το 11ty.
Τα λινκ των εσωτερικών σελίδων και το css έσπασαν όταν τα ανέβασα στο GH Pages. Χρειάστηκε να κάνω αλλαγές στο eleventy config αρχείο με τη βοήθεια του Gemini. Στο 11ty τα λινκ θα έπρεπε να ξεκινούν με "/" πχ "/src/style.css", επειδή τα αρχεία css και assets βρίσκονται χύμα μέσα στο φάκελο src.
